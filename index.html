사용자 순서 변경

카드를 드래그해서 순서를 바꿀 수 있어요. 이 순서는 지금 이 브라우저에만 저장되고, 다른 공대원에게는 영향을 주지 않아요.

로스트아크 API 키 설정

캐릭터명만 입력해서 직업/아이템레벨을 자동으로 불러오려면 API 키가 필요해요. 키가 없다면 로스트아크 홈페이지에서 로그인 후 무료로 발급받을 수 있어요.

자동조회가 브라우저 보안 정책(CORS)으로 막혀서 안 될 수도 있어요. 그럴 땐 등록 창에서 직업/아이템레벨을 직접 입력해주세요.

캐릭터 등록

등록자:
캐릭터명만 입력하세요. API 키가 있으면 직업/아이템레벨이 자동으로 채워져요.

레이드 목록 관리

공대에서 도는 레이드예요. 골드는 난이도별로 고정돼 있어서, 체크할 때 난이도만 선택하면 자동으로 반영돼요.
